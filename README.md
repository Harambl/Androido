# Бои отрядов

Пентяшкин Алексей Сергеевич\
Б9124-02.03.01мо

Небольшая игра про сражение двух отрядов(на данный момент двух солдат - лучника и воина).\
У каждого есть возможность атаковать, защищаться и использовать спецприем.\
Лучник пробивает блок, а воин становится неуязвимым на 1 ход.\
Ограничение на спецприем - 2 использования.
